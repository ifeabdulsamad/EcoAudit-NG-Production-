2. Diesel Consumption Per Hour

Formula:
kW = kVA × 0.8  →  litres/hour = kW × loadFactor × 0.28

What's happening:

  • A generator is rated in kVA (apparent power), but usable power is kW (real power). The conversion uses a power factor of 0.8 — industry standard for diesel gensets.
  • loadFactor = 0.7 means the generator typically runs at 70% capacity (not full load, not idle).
  • 0.28 L/kWh is the diesel burn rate — litres of diesel to produce 1 kWh. Real-world measured value for typical Nigerian gensets.
Example: 10KVA genset → 10 × 0.8 × 0.7 × 0.28 = 1.568 litres/hour

3. Per-Appliance Energy Consumption

Formula:
dailyKwh = (wattage × quantity × hoursPerDay) / 1000
monthlyKwh = dailyKwh × 30
annualKwh = dailyKwh × 365

What's happening:

  • wattage comes from applianceDatabase.js (e.g., AC 1HP = 746W, chest freezer = 350W)
  • quantity is how many of that appliance the user has (e.g., 3 ACs)
  • hoursPerDay is how long it runs per day
  • Divide by 1000 to convert watts → kilowatts
Example: 3 × AC 1HP (746W each), running 8h/day:
dailyKwh = (746 × 3 × 8) / 1000 = 17.9 kWh/day
annualKwh = 17.9 × 365 = 6,534 kWh/year

4. Grid vs Generator Split

Formula:
gridFraction = min(gridHoursPerDay / 24, 1)
genFraction = 1 - gridFraction

What's happening:

  • If the user gets 8 hours of grid (PHCN) per day:
    • gridFraction = 8/24 = 0.33 (33% of the time on grid)
    • genFraction = 0.67 (67% on generator)
  • The same appliance's annual kWh gets split proportionally between grid and generator.
Why this matters: Grid electricity costs ₦65/kWh, but generator electricity costs ~₦543/kWh. The split determines how expensive your energy is.

5. Cost Per kWh (Grid vs Generator)

Grid Cost: ₦65/kWh (flat NERC average tariff)

Generator Cost:
litresPerKwh = 0.28 / 0.85 = 0.329 L/kWh
costPerKwh = 0.329 × ₦1,650 = ₦543/kWh

What's happening:

  • Grid: flat ₦65/kWh (the Nigerian average electricity tariff)
  • Generator: 0.28 L/kWh ÷ 0.85 efficiency × ₦1,650/litre = ~₦543/kWh
  • Generator electricity is ~8× more expensive than grid — this is the core insight of the app

Per-appliance annual cost:

annualGridCost = gridAnnualKwh × 65;
annualGenCost = genAnnualKwh × 543;
annualCost = annualGridCost + annualGenCost;

6. Carbon Emissions (CO₂)

Per-kWh emissions from generator:
co2PerKwhGen = (2.68 × 0.28) / 0.85 = 0.884 kg CO₂/kWh

Total from appliance kWh:
annualCo2 = genAnnualKwh × 0.884

Total from fuel spend:
annualLitres = (monthlyFuelCost / 1650) × 12
totalAnnualCo2 = annualLitres × 2.68

What's happening:

  • Burning 1 litre of diesel produces 2.68 kg of CO₂ (IPCC standard)
  • It takes 0.28 litres to make 1 kWh (before efficiency loss)
  • With 85% efficiency, actual consumption is higher: 0.28 / 0.85 = 0.329 L/kWh
  • So: 0.329 L/kWh × 2.68 kg/L = 0.884 kg CO₂/kWh
  • Grid CO₂ is treated as negligible (the focus is on diesel)

8. Solar Package Matching

Match Score (max ~100):
sizeMatch ? +30 : 0   // Package suits business size
coverageRatio × 40      // How well it covers energy needs (0-40)
affordable ? +20 : 0   // Monthly payment ≤ 1.5× fuel budget
goldilocksZone ? +10 : 0 // System size 1×–2× actual need

Payback Period:

paybackMonths = pkg.totalPrice / (monthlyFuelCost × 0.75 × coverageRatio)

Assumes solar saves 75% of the fuel cost for the portion it covers.

11. Data Flow Summary

Input → Process → Output

User Input (3 steps):
Step 1: businessType, location, size, operatingHours
Step 2: generator {capacityKVA, hoursPerDay, fuelType}, gridHoursPerDay, appliances [{id, quantity, hoursPerDay}]
Step 3: monthlyFuelSpend (actual or estimated)

Processing (calculateAudit()):
1. For each appliance: calculate kWh/day → split by grid/gen → calculate cost & CO₂
2. Calculate total fuel consumption from generator specs
3. Use user's actual fuel spend (or calculated) for total annual cost
4. Calculate energy score from 5 weighted factors
5. Generate top 3 recommendations based on data analysis
6. Calculate carbon comparisons (Lagos-Abuja trips, Nigerian monthly avg)

Solar Matching (estimateSolar()):
1. Match audit results against 9 real Nigerian solar packages
2. Score each package (size, coverage, affordability, goldilocks zone)
3. Return top 6 matches with verdict (Viable/Marginal/Not Yet)

Output:
{ score, totalAnnualCost, totalAnnualCo2, applianceResults[], recommendations[], carbonComparisons, solarData }
